2) Track orders per ad→page pair without GA4
- Naming/UTMs: name each ad concept clearly and add UTMs like:
  utm_source=meta | utm_medium=paid-social | utm_campaign=ring-fit-first | utm_content=ring-offer-page-v1
- Shopify capture: orders include the first landing URL; to make it bulletproof, also write UTMs + landing page into cart attributes so they flow into every order:
  a) On page load, read the querystring + pathname.
  b) Populate hidden inputs on the cart form: attributes[utm_campaign], attributes[utm_content], attributes[landing_page].
  c) Shopify carries these attributes onto the order; export Orders CSV and pivot revenue by utm_campaign + utm_content to see the ad→page pairs that produced first orders.
- Creative variants: if multiple creatives hit the same page, add a short creative id in utm_term (e.g., c1, c2) so you can kill losers fast.
