30‑day attribution fix for River City Cycles

1) Event map (what to track, where, and with what value)
- purchase — fire on order confirmation. Params: value (GBP), currency, transaction_id, items [id/SKU, name, category, price, qty].
- booking_confirmed — fire on successful service booking confirmation (or webhook). Params: value (price/estimate), currency, service_type, booking_id, preferred_date.
- email_subscribe — fire on newsletter sign‑up success (footer). Params: form_location (footer/home), opt_in_method.
- click_to_call — fire on tel:0117… link click (and mark connected if your call tool supports it). Params: phone, page, source/medium if available.

2) Tag plan (mirror the same truth everywhere)
- GA4: send purchase and booking_confirmed as ecommerce/conversions; mark both as key events.
- Meta Pixel + CAPI: mirror purchase and booking_confirmed with value and currency so ads can optimise beyond clicks.
- Google Ads conversions: create separate conversions for purchase and booking_confirmed; import to campaigns.
- Dynamic Number Insertion (DNI): swap the 0117 line dynamically by source/medium; pass gclid/fbclid to call events so phone revenue isn’t “dark.”

3) UTM naming (enforce consistency across every link)
- Required: utm_source, utm_medium, utm_campaign. Optional: utm_content, utm_term.
- Conventions (lowercase, underscores only):
  • source: meta, google, pinterest, klaviyo, partnername
  • medium: paid_social, cpc, email, referral, organic_social
  • campaign: stream__offer__monthyear  e.g. ebikes__autumn_sale__oct2026
  • content: creative_variant  e.g. video1_square_blue
  • term: keyword for search

4) Consent Mode v2 (keep analytics lawful and useful)
- Enable in your CMP/GTM; map analytics_storage and ad_* signals for GA4/Google Ads; ensure Meta receives consent state via Pixel before firing events.

5) Cross‑domain booking (if any booking tool sits off‑site)
- Preserve UTMs/click IDs across domains with linker; after confirmation, send booking_confirmed back to GA4/Meta/Google Ads with original click IDs (server‑side if needed).

6) One report to run everything (source/medium × revenue)
- Columns: source/medium, sessions, add_to_cart, purchases, purchase_revenue (GBP), bookings, booking_revenue (GBP), click_to_call (count).
- Build in GA4 Explore: dimension Session source/medium; metrics Purchases, Purchase revenue; add Event count filtered to booking_confirmed and click_to_call; mark booking_confirmed as a conversion so it appears alongside purchases.
